# DNS-WIFI-RE
DNS-WIFI-RE сбособ изменения DNS сервера для wifi 
<h1>READTHIS</h1>
инструкция:
запустите help.bat
почитайте каждый интерфейс и проверьте у него SSID
если он равен вашему вайфаю то скопируйте имя интерфейса
<h2>(необязательно) проверка нынешнево DNS</h2>
пролистайте вниз и найдите имя того интерфейс
смотрим строчку DNS и вот нынешний dns сервер
<h2>изменение</h2>
запускаем main.bat (важно: запускать от имени админестратора)
вписываем имя интерфейса которое вы скопировали - enter - выбераем индекс (какой днс сервер хотим) - enter - иии готово!
